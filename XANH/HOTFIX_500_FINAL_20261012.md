# Xanh Sky First — Hotfix HTTP 500 (12/10/2026)

## Changes in this package

1. **Public UI runtime error:** the Be Vietnam Pro font key contains hyphens, so it is accessed with bracket notation rather than invalid dot-property syntax.
2. **Admin session parsing:** malformed percent escapes in unrelated cookies no longer throw from `decodeURIComponent` before Xanh can inspect its own session cookie.
3. **Settings compatibility:** the Admin settings read selects only `key` and `value_json`, which are the fields it consumes. The settings write path retries without the optional `updated_at` field only when the database explicitly reports that column missing; unrelated database errors are still thrown.
4. Regression tests were added for these cases. The existing code and configuration remain in place; no production credentials or deployed resources are included.
