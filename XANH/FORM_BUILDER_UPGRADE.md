# Xanh Sky First — Form Builder Upgrade

- Form Builder supports multiple independent forms managed from CMS.
- Field types: short text, email, phone, URL, long text, select, radio, checkbox, date, time, date-time, number, rating, file/image upload, handwritten signature, consent, section.
- Every non-section field can be Required or Optional. Public UI marks required fields and labels optional fields.
- Required checkbox groups are enforced client-side and server-side.
- Email and URL values are validated server-side; number/rating ranges are supported by the API.
- File/image uploads and handwritten signatures are stored through R2 upload flow; D1 stores references/metadata, not binary/base64 payloads.
- Submission codes remain unique and are generated by the server after a successful submission.
- Existing public rate limits, upload validation, unclaimed-upload tokens, open/close windows, capacity checks, guardian consent and role-based admin access remain in place.
- Confirmation email remains optional per form and is sent only after the submission is persisted.

Verification performed locally: `node --check` for modified JS, `npm test`, and `npm run check`.
